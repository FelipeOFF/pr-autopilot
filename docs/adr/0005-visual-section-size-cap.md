# Cap the PR visual section at two views and about eight sentences

The agent picks which show-me views fit the PR. Without a cap, a large diff
becomes a second document that competes with the diff itself. GitHub also
fails mermaid diagrams that grow past roughly 50–100 nodes.

The section is at most two views plus about eight sentences of briefing. A
large PR gets the slice the reviewer needs, not a map of the repository.
