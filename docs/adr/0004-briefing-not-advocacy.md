# The PR visual section briefs the reviewer; it does not sell the PR

`--show-me` exists so a human reviewer understands the change before reading
the diff. "Defend" here means show the decision: what the change does, the
trade-off, and the alternative that did not ship, with evidence (a file, a
constraint, a behavior).

It does not mean advocacy. No request to approve, no pre-empted objections
as a closing argument, no promotional adjectives. Those fight the humanizer
rules and they make the review less accurate, not more.

The heading is `## What this PR does`.
